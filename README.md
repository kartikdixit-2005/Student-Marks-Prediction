Student Marks Prediction Using Multiple Linear Regression

Project Overview

This beginner-level Machine Learning project predicts student marks using study hours and attendance.

Algorithm

Multiple Linear Regression

Input Features

- Study Hours
- Attendance

Target Variable

- Marks

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

Project Workflow

1. Create and inspect the dataset
2. Check missing and duplicate values
3. Visualize the relationship between inputs and marks
4. Split the data into training and testing sets
5. Train a Linear Regression model
6. Predict marks and evaluate model performance

Dataset

The notebook uses 10 sample records created within the Python code.

Evaluation

The notebook calculates MAE, MSE, RMSE and R² score. These metrics are based on a very small test set, so they should not be treated as proof of real-world accuracy.

How to Run

Open the ".ipynb" notebook in Google Colab or Jupyter Notebook and run the cells in order.
